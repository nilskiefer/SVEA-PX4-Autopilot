- Use **Powerboard** for battery/BMS baseline and INA monitor behavior.
- Use **Expanders** for `/dev/gpio*` mapping and rail-enable control.
- Use **Actuators** for PCA9685 and servo/throttle manual tests.
- Use **LEDs** for neopixel and LED pattern testing.
